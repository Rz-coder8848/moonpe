# moonpe 项目申报书

**项目**：moonpe —— 纯 MoonBit 的 Windows PE/COFF 映像解析库
**仓库**：https://github.com/Rz-coder8848/moonpe ｜ **发布**：Rz-coder8848/moonpe 0.5.0
**性质**：原创实现（对照微软 PE 规范，非移植）｜ **许可证**：Apache-2.0

**痛点**：MoonBit 已有 ELF 解析（moonbit-community/elf），但读不了 Windows 的 `.exe/.dll/.sys`。
10 月 21 日索引（3191 个包）检索，`coff`、`portable-executable`、`pe-parser`、`import-table` 均 0 命中。

**与既有库的关系**：`moonar` 处理 ar 归档与 COFF 对象（`.a/.lib/.obj`），moonpe 处理 PE 映像。
实测同一 `kernel32.dll`：moonar 报 `expected ar archive magic`，moonpe 报出 PE64/8 节/104 导入/1697 导出；
反过来 moonpe 打不开 `demo.a`，moonar 能列成员。共用部分只有格式规定的 COFF 头与节头，详见 `docs/对比说明.md`。

**交付范围**：DOS/NT 头、PE32/PE32+ 可选头、16 个数据目录、节表与 RVA 映射、导入、延迟导入
（RVA/VA 两种描述符）、导出、调试与 PDB、重定位、资源树、VERSIONINFO、TLS 回调、
CLR 运行时版本、应用清单 UAC 级别、运行时函数表、绑定导入，以及把结果转成判断的 `check`。

**为什么必须做延迟导入**：`shell32.dll` 静态导入 79 个、延迟加载 138 个，漏掉就是漏掉 64% 的依赖。

**明确不做**：执行、反汇编、签名验签、.NET 元数据表、图标/位图解码。

**完成标准**：README 的七条 v1.0 清单全部达成——可选头全字段、16 个目录命名映射、
依赖类全读、结构类全读、任意截断只报错、四个真实系统二进制验证、边界文档化。

**质量证据**：29 个测试（wasm 与 wasm-gc 双平台）、CI 全绿、0 warning、200 轮变异模糊测试；
真实样本 `kernel32`(32/64)、`shell32`、`notepad`、`mscorlib`。库只依赖 core，仅 CLI 用官方 `moonbitlang/x`。
